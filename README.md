## Projeto em destaque

### Next Boost

O **Next Boost** é uma aplicação de otimização para Windows desenvolvida para automatizar rotinas do sistema, melhorar o desempenho e proporcionar uma experiência mais fluida para os usuários.

Conduzi de forma independente todo o ciclo do produto, incluindo arquitetura, desenvolvimento, infraestrutura, evolução das funcionalidades, suporte e divulgação.

#### Resultados

* Mais de **5.000 usuários ativos**
* Ganhos de até **70% de FPS** em cenários relatados por clientes
* Mais de **13 mil seguidores** nas redes sociais
* Mais de **6 milhões de visualizações**
* Aplicação desktop desenvolvida com **Electron e React**
* API e funcionalidades de sistema desenvolvidas em **C#**
* Autenticação, banco de dados e serviços utilizando **Firebase**
